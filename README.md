# نظام متابعة معاملات طريبيل — v3

- صلاحيات مستقلة حسب الموظف: كل موظف يرى قسمه فقط.
- مدير النظام يرى جميع الأقسام.
- شاشة مستقلة للسكودة مع نسخ سريع للبيانات ومعالجة عدة معاملات.
- شاشة الأرشفة تجمع المعاملات المنتظرة والسكنر والقيم والأرشيف والتقارير في مكان واحد.
- الكشف يشمل الإشعاعي ضمن نفس المرحلة ولا يظهر الإشعاعي كمرحلة مستقلة.
- النقل البري مرحلة واحدة بدون مانيفست مستقل.
