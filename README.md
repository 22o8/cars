# نظام متابعة معاملات طريبيل — v5

نسخة تجريبية مبنية بـ Nuxt 3 / PWA، مع برنامج تحكم محلي اختياري لجهاز ASYCUDA.

## التحديثات الرئيسية
- قسم مستقل باسم «رقم الإجراء الموحد».
- صلاحية مستقلة لموظف رقم الإجراء؛ يشاهد هذا القسم فقط، بينما مدير النظام يشاهد كل شيء.
- قائمة معاملات بانتظار الإجراء مع رمز الشركة ورقم واتساب لكل معاملة.
- ربط مع Windows Local Agent على جهاز ASYCUDA عبر `127.0.0.1`.
- الوكيل المحلي يمكنه فتح `AWIQWorld.jnlp`، تسجيل الدخول، الوصول إلى شاشة رقم الإجراء، إدخال رمز الشركة، تنفيذ الإجراء، أخذ Screenshot وإرجاعه للنظام.
- محاولة قراءة رقم الإجراء تلقائياً إذا كانت خانة النتيجة قابلة للنسخ.
- إرسال Screenshot إلى الرقم المحدد عبر WhatsApp Cloud API عند تفعيل التكامل.
- بيانات دخول ASYCUDA وWhatsApp Token تبقى داخل Windows Credential Manager ولا تحفظ في تطبيق الويب.
- يستمر دعم كل وظائف v4: صلاحيات الأقسام، رفع سكنر لكل قسم، التجميع التلقائي PDF، الأرشفة والقيم المالية والتقارير.

## تشغيل تطبيق الويب
```bash
npm install
npm run dev
```

## إعداد جهاز ASYCUDA
راجع:
`local-agent/README.md`

ابدأ من:
`local-agent/install-agent.bat`

ثم:
`local-agent/calibrate.py`

وأخيراً:
`local-agent/start-agent.bat`

## Vercel
- Framework: Nuxt.js
- Build Command: `npm run build`
- Install Command: `npm install`
- لا تضبط Output Directory يدوياً.

## ملاحظة
التحكم في ASYCUDA يعتمد على معايرة أماكن الحقول والأزرار على نفس حاسبة Windows ودقة الشاشة. يجب استخدامه فقط على جهاز وحساب مصرح بهما من جهة العمل.
