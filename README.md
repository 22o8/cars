# نظام متابعة معاملات طريبيل — v4

نسخة تجريبية مبنية بـ Nuxt 3 / PWA.

## التحديثات الرئيسية
- كل موظف يرى قسمه فقط، والمدير يرى النظام كاملاً.
- شاشة مستقلة للسكودة.
- مرحلة مستقلة للفحص والتتبع مع الفحوص الإضافية عند الحاجة.
- موظفو الأقسام يرفعون أوراق السكنر من نفس قائمة معاملاتهم، مع دعم عدة معاملات في وقت واحد.
- كل ملف يرتبط تلقائياً بالمعاملة وبالقسم الذي رفعه.
- الأرشفة تعرض الملفات التي جُمعت من الأقسام، وتضيف سكنر الأرشفة والقيم المالية.
- عند اعتماد الأرشفة يتم جمع ملفات PDF والصور تلقائياً في PDF واحد مرتب حسب رحلة المعاملة.
- مدير النظام يستطيع فتح المعاملة ورؤية ملفات كل قسم وفتح/إعادة إنشاء/تنزيل الملف الموحد.
- تقارير يومية وتراكمية للأسعار والضريبة والرسوم.

## التشغيل
```bash
npm install
npm run dev
```

## Vercel
- Framework: Nuxt.js
- Build Command: `npm run build`
- Install Command: `npm install`
- لا تضبط Output Directory يدوياً.
