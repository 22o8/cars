# سجل النقل والمصروفات

نظام عربي PWA مبني باستخدام Nuxt 4 لتسجيل بيانات النقل والصرفيات والرسوم. يعمل على الهاتف والكمبيوتر، ويمكن تثبيته كتطبيق واستخدامه دون إنترنت بعد فتحه للمرة الأولى.

## الوظائف

- تسجيل اسم السائق ورقم السيارة والمرسل والمرسل إليه والبضاعة والتاريخ.
- إضافة عدد غير محدود من بنود الصرفيات.
- إضافة الرسوم وحساب المجموع النهائي تلقائياً.
- كتابة ملاحظة اختيارية.
- حفظ السجلات على الجهاز وتعديلها أو حذفها.
- طباعة سجل منسق.
- واجهة عربية متجاوبة ودعم PWA.

> الإصدار الحالي يحفظ البيانات داخل المتصفح على الجهاز نفسه. لا تنتقل البيانات تلقائياً بين الأجهزة.

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## البناء

```bash
npm run build
npm run preview
```

## النشر على Vercel

1. ارفع محتويات المشروع إلى مستودع GitHub جديد.
2. من Vercel اختر **Add New Project** ثم اربط المستودع.
3. سيتعرف Vercel على Nuxt تلقائياً؛ اضغط **Deploy**.

لا يحتاج هذا الإصدار إلى متغيرات بيئة.
