# نظام تتبع معاملات طريبيل

Nuxt 3 PWA عربية RTL لإدارة عدة معاملات بالتوازي، متابعة المراحل، الأرشفة بالسكنر، والقيم المالية اليومية والتراكمية.

## تشغيل محلي
```bash
npm install
npm run dev
```

## ملاحظات النسخة الحالية
- البيانات تحفظ محلياً في المتصفح LocalStorage.
- ملفات السكنر تحفظ في IndexedDB على الجهاز.
- النسخة الحالية مخصصة لتجربة واعتماد سير العمل والواجهات.
- عند اعتماد التصميم النهائي يتم نقل التخزين إلى قاعدة بيانات مركزية وتسجيل دخول حقيقي حتى تتزامن الحالات بين جميع الأجهزة.
