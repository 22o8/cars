# تثبيت نظيف — Tarabil ASYCUDA Agent v8.4

هذه النسخة مصممة للمجلد الثابت:

`C:\asycuda-office-1`

## لماذا ظهر "خطأ في برنامج الجهاز"؟

كان هناك سببان رئيسيان في النسخ السابقة:

1. فشل أي طلب كان يحول حالة الـAgent إلى `AGENT_ERROR` وتبقى هذه الحالة تُرسل للسيرفر حتى بعد انتهاء الطلب.
2. `restart-agent.bat` القديم لم يكن يعمل Restart حقيقياً؛ كان يحاول تشغيل نسخة جديدة بينما النسخة القديمة تبقى في الذاكرة، لذلك نسخ ملفات جديدة لا يعني أن الكود الجديد هو الذي يعمل.

v8.4 تصلح الاثنين.

## بداية نظيفة بالكامل

1. فك ضغط ملفات `local-agent` داخل:
   `C:\asycuda-office-1`
2. شغل:
   `reset-agent.bat`
3. شغل:
   `install-agent.bat`
4. أدخل عند الطلب:
   - رابط Vercel
   - Device ID
   - TARABIL_AGENT_DEVICE_TOKEN
   - اسم مستخدم ASYCUDA
   - كلمة مرور ASYCUDA
5. شغل:
   `install-autostart.bat`
6. شغل:
   `restart-agent.bat`

بعدها الجهاز يبدأ تلقائياً بعد كل Login إلى Windows.

## اختبار الاتصال

- افتح الموقع من الهاتف أو الكمبيوتر.
- يجب أن تظهر حالة الجهاز `متصل` طالما Windows مفتوح والـAgent يعمل.
- فشل طلب اختبار لا يحول حالة الجهاز إلى "خطأ في برنامج الجهاز".

## التحديثات المستقبلية

بعد هذا التثبيت النظيف لا تعيد التثبيت من الصفر كل مرة.

1. انسخ ملفات `local-agent` الجديدة فوق `C:\asycuda-office-1`.
2. لا تحذف `config.json` ولا `.venv` ولا `.venv32`.
3. شغل:
   `update-agent.bat`

هذا الملف يحدث المكتبات، يشغل الاختبارات، ويفعل Restart حقيقي للـAgent.

## ملاحظة Java Security Warning

v8.4 تتحقق أولاً من أن النافذة تخص `https://asy.mof.gov.iq` ثم تحاول تشغيلها بعدة طرق آمنة. آخر fallback يستخدم أبعاد نافذة التحذير الحالية نفسها، وليس إحداثيات سطح مكتب محفوظة.
