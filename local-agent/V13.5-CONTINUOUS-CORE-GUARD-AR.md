# v13.5 Continuous Core Guard

قواعد أساسية غير قابلة للكسر:

- Security Warning الرسمي لـ `asy.mof.gov.iq` يراقَب دائماً بخيط مستقل عن الطلبات.
- Login يبقى Native/JAB fallback.
- أي صفحة أو Popup مفتوح داخل ASYCUDA يتحول إلى Screenshot + مراجعة بدل فشل.
- الصفحة الرئيسية تستخدم Fast Path إلى الإجراء الموحد ثم رقم الإجراء الموحد.
- التنفيذ الحقيقي يحافظ على Enter بعد رمز الشركة ثم ينتظر دليلاً حقيقياً على إنشاء الرقم قبل النجاح.
